## ⚡ 𝐒𝐈𝐘𝐀𝐌 𝐓𝐄𝐋𝐄𝐆𝐑𝐀𝐌 𝐁𝐎𝐓 ⚡

A Telegram adaptation of the original Goat Bot project.
The project uses Node.js and Telegram Bot API.

## ✨ Features

- Telegram message handling
- Prefix-based commands
- Admin and owner configuration
- Modular command loading
- Database support
- Dashboard support
- Automatic restart options

## 📦 Requirements

- Node.js 20 or newer
- npm
- Telegram Bot Token
- Telegram User ID
